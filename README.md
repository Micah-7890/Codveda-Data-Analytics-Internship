# Codveda Data Analytics Internship

## Overview
This repository contains data analytics projects completed during the Codveda Technology internship program.

## Levels
### Level 1 - Basic
- Task 1: Data Cleaning & Preprocessing (Stock Prices)
- Task 2: Exploratory Data Analysis (Iris Dataset)

### Level 2 - Intermediate
- Task 1: Regression Analysis (Boston Housing Dataset)
- Task 2: Time Series Analysis (Apple Stock)

### Level 3 - Advanced
- Task 1: Predictive Modeling - Classification (Churn Dataset)
- Task 3: NLP Sentiment Analysis (Sentiment Dataset)

## Tools & Libraries
Python, pandas, numpy, matplotlib, seaborn, scikit-learn, statsmodels, nltk, TextBlob, wordcloud
